💈 Barbearia Top Sistema simples de agendamento para barbearia desenvolvido com HTML, CSS e JavaScript. O projeto foi criado com base em estudos e prática de programação, utilizando como referência um tutorial do YouTube, além de melhorias e adaptações realizadas com auxílio de Inteligência Artificial para aprimorar funcionalidades, organização e experiência do usuário.

🚀 Tecnologias Utilizadas

HTML5

CSS3

JavaScript

📂 Estrutura do Projeto 📁 barbearia-top ├── index.html ├── style.css └── script.js

📋 Funcionalidades ✅ Cadastro de agendamentos ✅ Escolha de serviços ✅ Seleção de data e horário ✅ Exibição dinâmica dos agendamentos ✅ Interface simples e responsiva

🖥️ Como Executar o Projeto

Faça o download ou clone este repositório:

git clone https://phenriquees.github.io/Agendamentos-barbearia/

Abra a pasta do projeto.

Execute o arquivo index.html no navegador.

✨ Exemplo de Uso

Digite seu nome

Escolha o serviço desejado

Selecione a data

Escolha o horário

Clique em Agendar

O agendamento aparecerá automaticamente na lista.
